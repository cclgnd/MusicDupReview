# Music Duplicate Review

Desktop tools for scanning, reviewing, and safely resolving duplicate media files.

## Run the GUI

Double-click `Launch_PySideReview.bat` or run:

```powershell
python -m pyside_app.main
```

Legacy Tkinter GUI: double-click `Launch_DupReview.bat` or run `python dup_review_gui.py`.

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

Run tests:

```powershell
python -m unittest discover -s tests
```

Optional scan configuration:

```powershell
$env:MUSIC_DUP_ROOT="D:\path\to\music"
$env:MUSIC_DUP_DB="D:\path\to\music_library.db"
$env:MUSIC_DUP_REPORT_DIR="D:\path\to\reports"
```

## Files

- `dup_review_gui.py` — main GUI app (Tkinter + pygame + send2trash)
- `pyside_app/` — PySide6 app with Duplicate Removal, File Explorer, Utilities, and Settings views
- `docs/gui_architecture.md` — accepted GUI engine and migration architecture
- `Launch_DupReview.bat` — double-click launcher
- `music_library.db` — local SQLite database generated by scans; not committed
- `reporte_audio_md5.md` — local generated detection report; not committed
- `duplicados_audio_md5.csv` — local generated duplicate list; not committed

## Database tables

- `archivos` — every file (audio, image, list, info, meta), with full MD5, audio MD5, hidden flag, size, etc.
- `duplicados` — duplicate groups by detection type (md5 / audio_md5 / nombre_exacto)
- `decisiones` — your keep/delete/move choices (persisted across sessions)

## Scripts

- `scan_all.py` — full filesystem scan, hashes everything
- `audio_md5_all.py` — computes audio-only MD5 (skips ID3 tags) for all MP3
- `detect_fast.py` — re-detect duplicates from existing hashes
- `report_audio_md5.py` — regenerate the MD/CSV report

## Workflow

1. Open GUI
2. Use Utilities > `Scan Folder...` to build or update the database
3. Review duplicate groups while scans/searches run in the background
4. Use the selected-file preview to inspect path, size, hashes, and state
5. Filter by `audio_md5` when you need the safest duplicate signal
6. Mark one file as `Keep`
7. Mark unwanted files as `Trash`
8. Use `Apply` by selected groups, page, or whole database
9. Files go to Recycle Bin only; no permanent delete path is used

## Current PySide usability

- Background folder scans with cancel, live rate, recent scan history, and completion popup.
- Background Duplicate Removal and File Explorer refreshes so the window stays responsive.
- Selected-file preview with open file/folder actions.
- Utilities integrity report for missing files, orphan rows, incomplete duplicate groups, and hash errors.
- Settings view for active database and default scan folder.
