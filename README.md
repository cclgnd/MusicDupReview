# Music Duplicate Review

Desktop tools for scanning, reviewing, and safely resolving duplicate media files.

## Run the GUI

Double-click `Launch_DupReview.bat` (or run `python dup_review_gui.py`).

PySide6 migration shell: double-click `Launch_PySideReview.bat` or run `python -m pyside_app.main`.

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

Run tests:

```powershell
python -m unittest discover -s tests
```

Optional scan configuration:

```powershell
$env:MUSIC_DUP_ROOT="D:\path\to\music"
$env:MUSIC_DUP_DB="D:\path\to\music_library.db"
$env:MUSIC_DUP_REPORT_DIR="D:\path\to\reports"
```

## Files

- `dup_review_gui.py` — main GUI app (Tkinter + pygame + send2trash)
- `pyside_app/` — PySide6 migration shell with Duplicate Removal, File Explorer, Utilities views
- `Launch_DupReview.bat` — double-click launcher
- `music_library.db` — local SQLite database generated by scans; not committed
- `reporte_audio_md5.md` — local generated detection report; not committed
- `duplicados_audio_md5.csv` — local generated duplicate list; not committed

## Database tables

- `archivos` — every file (audio, image, list, info, meta), with full MD5, audio MD5, hidden flag, size, etc.
- `duplicados` — duplicate groups by detection type (md5 / audio_md5 / nombre_exacto)
- `decisiones` — your keep/delete/move choices (persisted across sessions)

## Scripts

- `scan_all.py` — full filesystem scan, hashes everything
- `audio_md5_all.py` — computes audio-only MD5 (skips ID3 tags) for all MP3
- `detect_fast.py` — re-detect duplicates from existing hashes
- `report_audio_md5.py` — regenerate the MD/CSV report

## Workflow

1. Open GUI
2. Filter by `audio_md5` (safest — provably identical audio)
3. Mark one file as `Keep`
4. Mark unwanted files as `Trash`
5. Use `Apply` by selected groups, page, or whole database
6. Files go to Recycle Bin only; no permanent delete path is used
